Anthropic is making auto mode the default in Claude Code for Pro, Max, and Team plans starting August 14, where a classifier evaluates and blocks potentially harmful agent commands instead of requiring per-command approval. This addresses the speed-vs-safety tradeoff in long-running and parallel agentic coding sessions.
