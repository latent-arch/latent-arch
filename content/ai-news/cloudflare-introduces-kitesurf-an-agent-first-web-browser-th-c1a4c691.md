Cloudflare released Kitesurf, a stateless agent-first web browser running entirely in V8 isolates on Cloudflare Workers with no Chromium, built in Rust and passing 215,000+ Web Platform Tests. It reports 3-4x less CPU and 5-7x less memory usage, targeting AI agents rather than human users.
