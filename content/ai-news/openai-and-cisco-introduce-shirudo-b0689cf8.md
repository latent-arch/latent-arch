OpenAI and Cisco released Shirudo, an open-source BSD-licensed eBPF runtime for Linux that lets AI agents write signed 'shields' to block exploit paths on running systems while patches are tested and deployed. It's a notable collaboration bringing AI agents into defensive security operations.
