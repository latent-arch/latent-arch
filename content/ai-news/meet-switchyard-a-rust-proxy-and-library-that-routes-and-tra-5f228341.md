NVIDIA released Switchyard, an Apache-2.0 Rust proxy and library that routes and translates LLM traffic between OpenAI and Anthropic API formats, letting tools like Claude Code or Codex CLI run against vLLM, NIM, or Ollama unchanged. It's pre-alpha and not production-ready.
